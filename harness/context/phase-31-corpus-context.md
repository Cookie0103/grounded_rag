# 阶段 31 语料与版本决策

- 公开资料用独立可见 Chrome 标签页按清单访问。原生保存窗口未能选中时，把当前已渲染的 HTML 提交到仅监听本机环回的临时表单。表单只写本地文件，结束后关闭；Chrome 访问日志和文件哈希用来核对采集。
- 公开页面的生效日期取本机保存日期，表示本次快照开始可用于检索。模拟内部规程用本地日文模板和固定种子，引用已校验的公开资料 ID；月度利率值专为版本测试而虚构。干扰层只使用虚构产品模板，减少生成成本并保证重复生成。生成语料和入库没有调用付费模型。
- 版本使用 `[effective_from, effective_to)`，已发布的下线版本只在历史有效区间可见。发布事务更新文档和子块，重复入库由内容哈希跳过，保留数据库中的发布状态。
- PostgreSQL 持有规程写锁并作为权威快照。Elasticsearch 核对写入块数后原子切换查询别名。同步发生故障时重新运行入库命令即可根据 PostgreSQL 重建。
- 新增 Elasticsearch 8.19.3 异步客户端，与 Elasticsearch 8 的服务匹配。CI 集成测试需要本地 ES 和 kuromoji，因此增加了启动单个 ES 服务的步骤，既有检查门槛保持原值。
