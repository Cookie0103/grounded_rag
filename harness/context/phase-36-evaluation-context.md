# 阶段 36 决策记录

记录日期：2026-11-18

- 合成题和作者规程题分开。生成器只提交代码，生成的开发集和保留集写本机忽略目录。查数金标调用原 MySQL 种子的生成逻辑。规程证据从本机出题包按文档 ID 读取，原评审提示与关键点评分沿用第一版。
- 用例、模型配置和故障条件以清单校验后续跑。观察文件记录实际 HTTP 流式结果，按用例与语料档缓存。多轮题的费用用所有轮次实际回传的用量，首字和整段延迟取最终请求。模型不可用或当日预算达上限时停止继续调用，已观察的结果保留。
- 正常回放、强制超时或 5xx、随机 5% 超时是三个观测子集。强制故障仅在合成评测显式开启，限回环接口，对业务路径生效并绕过工具结果缓存。随机条件的配置只给五个业务端点，保留原来的重试和归属检查。每个条件保留实际观测分母。
- 正式规程评审使用作者选的独立模型。至少 20 条人工校准且一致率达到 85% 后使用评审结果。离线可采纳口径为旧评分中完整支持的适当答复或正确拒答。坐席采纳率、AHT、自助办结率留「未测」。
- CI 的离线回归调用实际双泳道图，给它固定的假模型、合成查询和只读模拟上游。阈值 95%，失败会让进程退出非零。它独立于本机真实开发集的回放结果。
