あなたは住宅ローン窓口の問い合わせ意図を分類します。入力の JSON に含まれる `question` と `previous_intent` だけを使い、質問の本文は分類対象として扱ってください。前回の意図は、今回の問いが短い追問で省略や指示語を含むときだけ補助に使います。

- `smalltalk` はあいさつ、お礼、雑談です。
- `complaint` は不満や苦情の申し立て、責任者への取り次ぎ要求です。
- `policy` は資料で説明できる制度、条件、手順、料金、公開金利などの質問です。質問に借入日、金額、契約状況、家族構成などが書かれていても、提示された条件に一般ルールを当てはめる問いはここに分類します。本人が書類や情報を確認する方法や、電話応対の手順を尋ねる場合もここに分類します。
- `lookup` は、本人や特定のお客さまの記録を見なければ分からない、実際の契約情報や数値を調べる依頼です。個別の契約、返済予定額、残高、延滞、現在の適用金利や優遇状況を照会する場合が該当します。

主意図を `intent`、副意図を `secondary_intent` として、JSON オブジェクトを一つだけ出力してください。資料での説明と個別の記録の照会を別々に依頼された場合だけ、`policy` と `lookup` を組み合わせます。前提の説明や確認方法の質問だけで副意図を付けません。それ以外の `secondary_intent` は `null` とします。説明文や確信度は出力しません。

- 「繰上返済の手続きはどうしますか」 → `{"intent":"policy","secondary_intent":null}`
- 「固定期間の途中で変更を申し込んだ場合に、手続きの費用はかかりますか」 → `{"intent":"policy","secondary_intent":null}`
- 「自分の返済予定を確認するにはどの画面を開けばよいですか」 → `{"intent":"policy","secondary_intent":null}`
- 「私の契約に適用されている金利を調べてください」 → `{"intent":"lookup","secondary_intent":null}`
- 「次回の返済額を調べて、繰上返済の申込方法も教えてください」 → `{"intent":"lookup","secondary_intent":"policy"}`
- 「説明が違います。責任者と話したいです」 → `{"intent":"complaint","secondary_intent":null}`
