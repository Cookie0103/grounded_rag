## 你要输出的内容

只输出**一个 JSON 对象**，不要有任何其他文字，也不要用代码块包裹：

```
{
  "nuggets": [...],
  "contradiction": false,
  "behavior": "answered",
  "corrects_premise": false,
  "covers_interpretations": false
}
```

各字段的含义：

- `nuggets`：数组，**每条关键点一个标签，顺序和上面的关键点一致，数量也要一样**（没有关键点就输出空数组）。标签只能是：
  - `"support"`：回答**完整**地包含了这条关键点的意思（措辞不同没关系）；
  - `"partial_support"`：回答只包含了这条关键点的一部分，或者说得含糊；
  - `"not_support"`：回答没有包含这条关键点，或者说的和它相反。
- `contradiction`：回答里是否有**和金标文档矛盾**的说法，或者金标文档里**根本没有**的具体做法、数值、名称（编造）。只是漏了内容不算。
- `behavior`：系统的行为——
  - `"answered"`：直接给出了答案或做法；
  - `"clarified"`：没有直接回答，而是反问用户、请用户补充信息；
  - `"refused"`：拒绝回答，或明确说明文档里没有相关内容、超出范围。
- `corrects_premise`：回答是否指出了**问题里的前提不成立**（例如问题默认某功能存在，但文档说它不存在或做法不同）。
- `covers_interpretations`：问题含糊时，回答是否**同时**给出了几种理解下的答案（例如分别说明云版和自部署版怎么做）。

判断时：

- 回答里多出来的、金标文档里有依据的正确内容，不算矛盾；
- 回答很长不代表好，要逐条核对关键点；
- 回答是空的或只有错误信息时，所有关键点都是 `"not_support"`，`behavior` 按实际情况填。
