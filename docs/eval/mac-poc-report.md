# Mac 本机实测报告

本报告汇总阶段 30 至 37 已观察到的工程指标。正式日文规程开发题、人工校准、封存集和 Dify 的真实同题回放待补。合成开发题与短样例的结果各自列明。

## 运行条件

- Apple M4 Max，64 GB 统一内存；Docker Desktop 分配 24 GiB，运行时观察到约 23.43 GiB。Qwen3 嵌入和精排用 MPS。小模型 Ollama Qwen3 4B Instruct 在本机运行，生成模型为经 LiteLLM 转发的 DeepSeek V4 Pro。 [Mac 环境记录](../../harness/context/phase-30-mac-context.md)
- 大批开发题在本机单请求并发度下串行回放。预热检索和小模型各一次，首字从 HTTP 客户端请求起算，整段计到最终 `answer`。第一版 Windows P95 留在原历史记录。 [阶段 36 证据](../../harness/build/phase-36-evaluation.md#记录)

## 语料与检索

S 档 185 篇，L 档 3,000 篇，共 3,213 个规程块入库。阶段 32 的独立 30 条合成检索冒烟中，两档均 Top5 命中 30/30；默认混合模式 S、L 的检索 P95 分别为 38.62、41.88 毫秒。正式规程的 S/L 同题差值、区间和是否能代表更大规模仍未测。 [语料验收](../../harness/build/phase-31-corpus.md#记录) · [检索冒烟](../../harness/build/phase-32-retrieval.md#记录)

同一 Mac 的阶段 35 预热短样例首字 P95 为 2.346 秒，整段 4.254 秒，20 条里观测到 0 次撤回。另一次未预热重连样例服务首字为 5.231 秒，该次小模型意图节点为 4.141 秒。节点耗时和复运行命令见[流式实测](../../harness/build/phase-35-streaming-guard.md#记录)。

## 已知边界

- 模拟业务、权限和故障注入只反映本机样例。真实贷款审查、费率承诺、写入业务、线上流量、灰度切流和生产回滚都在本项目范围外。
- 坐席混合意图实现查数与规程组合，其他组合未覆盖。流式输出收到完稿后做校验，必要时以撤回事件替换已显示片段。
- LiteLLM、数据服务和 Dify 都在本机。生成走外部 API；配置 Langfuse 时沿用现有云端选项。
- Dify 与 LangGraph 可复用相同的嵌入权重，LangGraph 的检索查询另加日文任务指令。Dify 真实索引配置、过期过滤、回放和逐节点证据仍需实际控制台验收。
- 仓库为公开仓库。当前实现与验收提交保存在本机，是否推送由作者决定。
